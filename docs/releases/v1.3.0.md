## XCloudSSD v1.3.0

**Unduh:** `XCloudSSD-Setup.exe` (installer, disarankan) atau `XCloudSSD-Portable-x64.zip`. Windows 10/11 x64.
Installer memasang WinFsp (jika belum ada), rclone bawaan, dan XCloudSSDService.

### Yang baru
* **Drive dipasang oleh rclone** (v1.75.2 resmi, dibundel) dengan **cache lokal di disk** — default
  `C:\ProgramData\XCloudSSD\Cache`, bisa diganti di Settings. Install game secepat disk; upload ke cloud berjalan di
  latar belakang dan tampil di Transfer Manager. Upload yang belum selesai dilanjutkan setelah restart.
* **TeraBox didukung lewat rclone** melalui jembatan WebDAV lokal (127.0.0.1, password acak per akun).
* **Google Drive** lewat backend `drive` resmi rclone (OAuth client milik Anda sendiri).
* Volume dilaporkan sebagai **NTFS** dengan izin penuh untuk Everyone (mengatasi Steam "MISSING FILE PRIVILEGES").
* Upload TeraBox memakai server sesuai region/domain akun (mengatasi error 31045 "user not exists").
* Settings → *Mesin mount & cache lokal*: rclone / mode lama hanya-RAM, folder cache, ukuran maks., sisa ruang
  kosong, umur cache, jeda upload, upload paralel.

### Penting
* C: perlu ruang cukup untuk game yang sedang di-install sampai upload selesai.
* TeraBox gratis: maks. 4 GB per file. TeraBox lewat antarmuka web tidak resmi.
* Diuji di CI dengan mount rclone + WinFsp sungguhan dan cloud tiruan; **belum diuji dengan akun Google/TeraBox
  sungguhan**. Lihat `docs/LIMITATIONS.md` dan `docs/TESTING.md`.
