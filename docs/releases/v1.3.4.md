## XCloudSSD v1.3.4

**Unduh:** `XCloudSSD-Setup.exe` (installer) atau `XCloudSSD-Portable-x64.zip`. Install di atas versi lama; cache dan akun tetap.

### Perbaikan: upload file besar TeraBox berulang dari nol
Penyebab (dari log): file > 4 GB (`data1.cpk` 5,2 GB, `movie2.cpk` 10,5 GB, `Dungeons-Windows.ucas` 8,5 GB) diunggah
sampai habis, lalu TeraBox menolaknya di langkah terakhir dengan `errno 58 "upload single file vip limit"` — batas
akun gratis 4 GB per file. rclone mencoba lagi dari awal, terus-menerus.

* File di drive TeraBox sekarang disimpan memakai backend resmi rclone **chunker**: file di atas 3 GiB dipecah menjadi
  potongan 3 GiB (`nama.rclone_chunk.001`, `.002`, …) dan tetap tampil serta terbaca sebagai **satu file** di drive.
  File kecil disimpan seperti biasa. File lama tidak berubah.
* Error `errno 58` sekarang dijelaskan sebagai batas ukuran file TeraBox.
* Kolom percobaan di Transfer Manager memakai hitungan rclone yang sebenarnya (sebelumnya angka melonjak, mis. 18655).

Catatan: di aplikasi/web TeraBox, file besar terlihat sebagai beberapa potongan; buka lewat drive XCloudSSD.
