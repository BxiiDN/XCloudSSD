## XCloudSSD v1.3.3

**Unduh:** `XCloudSSD-Setup.exe` (installer) atau `XCloudSSD-Portable-x64.zip`. Install di atas versi lama; cache dan akun tetap.

### Perbaikan: "unchunked simple update failed … context canceled"
Penyebab: saat Steam mengunduh game, file di `steamapps\downloading` terus ditulis lagi lalu dipindah ke
`steamapps\common`. Setiap tulisan baru / pemindahan membatalkan upload yang sedang berjalan (perilaku rclone), lalu
upload mulai dari nol — bandwidth terbuang dan Transfer Manager penuh pesan "context canceled".

* File di folder staging Steam (`steamapps\downloading`, `steamapps\temp`, `workshop\downloads`) sekarang **menunggu
  di cache C:** dan tidak diunggah. Setelah Steam memindahkan file ke folder akhirnya, file langsung diunggah — sekali.
  Transfer Manager menampilkan statusnya sebagai *Pending* dengan keterangan.
* Upload dimulai setelah file tidak disentuh selama **60 detik** (sebelumnya 5 detik), jadi lebih sedikit upload yang
  dibatalkan saat launcher masih menulis.
* Upload paralel default 3 per drive (sebelumnya 4), dan TeraBox `408 read request body timeout` sekarang dicoba ulang.
