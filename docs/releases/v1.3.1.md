## XCloudSSD v1.3.1

**Unduh:** `XCloudSSD-Setup.exe` (installer) atau `XCloudSSD-Portable-x64.zip`. Install di atas versi lama; akun dan cache tetap.

### Perbaikan
* **TeraBox: upload file > 4 MB gagal** dengan `unchunked simple update failed` / `TeraBox /api/create: errno 2 "param err"`
  di Transfer Manager. Penyebab: upload multi-bagian di-*precreate* seperti file satu bagian. Sekarang mengikuti cara
  klien web TeraBox, sehingga file besar (exe, dll, pak, mp4) bisa dibuat.
* Ukuran bagian upload TeraBox otomatis membesar untuk file > 4 GB (akun premium).

File yang tadinya gagal tetap aman di cache C: dan akan diunggah ulang otomatis setelah update.
